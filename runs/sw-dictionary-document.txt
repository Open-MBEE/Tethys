# Argent flight dictionary

Every command, telemetry point, event and packet the Argent flight software and the Meridian ground system agree on, read from TethysFlightDictionary. Opcodes, mnemonics, application ids and event ids are unique; the dictionary requirement in TethysOperations checks it.
