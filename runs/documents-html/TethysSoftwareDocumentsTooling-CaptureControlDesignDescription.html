Capture control application design description

Purpose

Application definition
name type documentation
CaptureControlApplication Capture system control: the enclosure sequence, the cinch inhibit chain and the despin, safety-critical because the cinch is the hazardous function of the inhibit chain.
Behavioural specialisation
name type documentation
CaptureControlSoftware The capture application exhibiting the capture controller; the controller's inhibits are the software interlocks of the inhibit chain.
