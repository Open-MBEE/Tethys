Mode management application design description

Purpose

Application definition
name type documentation
ModeManagementApplication Mode and safe-mode management: the tug mode machine realised in software, taking ground commands and on-board events on the command port and holding the current mode every other application reads.
Behavioural specialisation
name type documentation
ModeManagementSoftware The mode manager: TugModes exhibited as the software mode machine on `command`, beside the dispatcher that turns each mode command it receives on `dispatch` (the command ingest's second copy of the uplink) into the application commands the mode's SubsystemConfiguration row implies and reports each dispatch on the event port. FDIR requests arrive on `fdirRequests`; the dispatcher raises them on the application for the mode machine and sheds the applications.

flightMode
sepString The solar-electric propulsion string: off until commissioning, standby between arcs, thrusting during one and during the approach until the rendezvous range update; off in safe mode.
telecom Deep-space link: low-gain omni from launch and in safe mode, high-gain when pointed; the proximity relay is on with the inspector in flight.
attitudeControl Reaction wheels for cruise and thrust; hydrazine thrusters for proximity operations, capture and despin, and for the sun-pointed safe mode.
captureMechanism Capture bag: stowed until CaptureGo, deployed during capture, cinched on completion, released at disposal.
