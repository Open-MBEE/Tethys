Pass planner (Meridian Almanac) design description

Purpose

Component definition
name type documentation
PassPlanner Meridian Almanac, the pass planner: from the stations' visibility of the tug and the MLS-2 rate set of the planned mode it allocates the day's passes, resolves the conflicts between the three stations and the relay windows, and writes the DailyPassPlan the operations model flies.
