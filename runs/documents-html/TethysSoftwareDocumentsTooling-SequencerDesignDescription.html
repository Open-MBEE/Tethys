Sequencer and flight-rule checker (Meridian Warden) design description

Purpose

Component definition
name type documentation
FlightRuleChecker Meridian Warden, the sequencer and flight-rule checker: every planned sequence is loaded, checked against FR-001 to FR-004 and either released to the uplink queue as a LoadSequence command or refused. The release is a send from this part's own port inside its performed action, the form the pinned runtime routes.
