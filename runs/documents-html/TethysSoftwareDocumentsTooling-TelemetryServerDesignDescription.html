Telemetry server (Meridian Lantern) design description

Purpose

Component definition
name type documentation
TelemetryServer Meridian Lantern, the telemetry server: synchronises the transfer frames the gateway forwards, decommutates every dictionary packet by its PacketDefinition layout, converts to engineering units, checks the dictionary limits and the FDIR limit table, raises alarms and trends the resource points.
