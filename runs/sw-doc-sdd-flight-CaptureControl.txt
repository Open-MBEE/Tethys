# Capture control application design description

## Purpose

*Application definition*

| name | type | documentation |
| --- | --- | --- |
| CaptureControlApplication |  | Capture system control: the enclosure sequence, the cinch inhibit chain and the<br>despin, safety-critical because the cinch is the hazardous function of the<br>inhibit chain. |

*Behavioural specialisation*

| name | type | documentation |
| --- | --- | --- |
| CaptureControlSoftware |  | The capture application exhibiting the capture controller; the controller's<br>inhibits are the software interlocks of the inhibit chain. |
