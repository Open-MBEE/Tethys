# WP-G coverage — variants, KerML physics library, notation sweep

Owned files: `model/80-variants.sysml` (TethysVariants), `model/81-physics.kerml` (TethysPhysics),
`model/82-notation-sweep.sysml` (TethysNotation). Every row is proved by a run in `scripts/runs.sh`
whose output is pinned under `runs/`; the run names below are those. `validate` is the OpenSysML
validation of every model file (`make validate` runs it with `-strict -warnings-as-errors`); the two
`.sysml` files also pass the standalone pilot (`make pilot-mission`) and all three the batch pilot
(`make pilot-all`). The KerML library is in addition clean under the pilot's own KerML oracle
(OpenSysML `build/pilot-kerml-validator/validate-kerml`), which the standalone wrapper cannot run
(F-G01). Tool boundaries met on the way are in `docs/findings/WP-G.md`.

Rows of the WP-G groups that stay open are marked `open` with the reason; `could` rows are listed
only where a construct of the model happens to exercise them.
