# Findings against OpenSysML, the model and the software — WP-SW-13 (conformance)

Same columns as `docs/findings.md`; ids are renumbered at integration. Timings are wall-clock on the
development VM; the tool is the pinned OpenSysML `5cd37f288` (`sysml`, `sysml-grpc` and the Python client
at that commit). Where a row is an adjudication between the flight host and the model, the spec clause it
rests on is named and the other side is the defect; where it is a tool defect, a minimal probe is named.
